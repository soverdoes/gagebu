# 두 사람 가계부

부부·동거인 두 사람이 한 화면에서 쓰는 월별 가계부입니다. 서버 없이 HTML 한 장으로 동작하고,
입력한 내용은 **그 브라우저에만** 저장됩니다. 어디로도 전송되지 않습니다.

**[→ 바로 쓰기](https://soverdoes.github.io/gagebu/)**

## 무엇을 할 수 있나

- **월별 장부** — 두 사람의 수입 / 저축 / 고정비 / 용돈을 나란히. 항목마다 납부 체크
- **카드 세부 내역** — `∑` 를 켜면 하위 내역 합계가 곧 카드 결제액이 됩니다
- **지출 출처 구분** — 각 줄을 `월급` / `비빅(비상금에서 지출)` / `제외` 로 표시.
  비빅은 카드 청구액에는 들어가되 월급 지출 합계에서는 빠집니다
- **비상금 통장 흐름** — `잔액 − 비빅 지출 = 남은 비상금 + 이번 달 남은 금액 → 다음 달 이월`
- **식생품 예산** — 카드값에서 결제된 고정 내역만 체크해 빼고, 예산 대비 쓸 수 있는 금액을 봅니다
- **총자산** — `우리 총자산`(만기·금리)과 `노후 자금`(원금·평가손익) 두 묶음으로 분리
- **저축 → 계좌 연동** — 저축 항목을 체크하면 연결된 계좌 잔액에 자동으로 더해집니다
- 실행취소/다시실행(`Ctrl+Z`), 드래그로 순서 변경, 다크 모드, JSON 내보내기·불러오기

## 쓰는 법

`index.html` 을 브라우저로 열면 끝입니다. 로컬 서버로 열면 더 좋습니다.

```
python _serve.py     # http://localhost:8080
```

`http://localhost` 는 보안 컨텍스트라 **파일 저장 위치를 직접 고를 수 있고**,
저장 원본이 주소로 고정돼 자동 저장이 안정적입니다.

## 로그인 · 여러 기기에서 함께 쓰기

기본은 **브라우저 저장**입니다. 서버가 없으니 데이터가 어디로도 나가지 않지만,
기기를 옮기려면 `파일로 저장` → `불러오기` 를 거쳐야 합니다.

Firebase 를 붙이면 **구글 로그인 + 서버 저장**이 켜지고, 두 사람이 같은 가계부를
폰·PC 어디서든 함께 보게 됩니다. 공개 주소로 들어와도 **로그인한 본인 가계부만** 보입니다.

### 설정 (한 번만, 약 10분)

1. [Firebase 콘솔](https://console.firebase.google.com) 에서 프로젝트를 만듭니다 (Analytics 는 꺼도 됩니다)
2. **Authentication → Sign-in method → Google** 을 켭니다
3. **Authentication → Settings → 승인된 도메인** 에 배포 주소를 추가합니다
   (예: `soverdoes.github.io`. `localhost` 는 기본으로 들어 있습니다)
4. **Firestore Database → 데이터베이스 만들기** → *프로덕션 모드* 로 시작합니다
5. **Firestore → 규칙** 탭에 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 통째로 붙여넣고 게시합니다
6. **프로젝트 설정 → 내 앱 → 웹 앱 추가** 로 설정 객체를 받아
   [`firebase-config.js`](firebase-config.js) 의 `null` 자리에 붙여넣고 커밋·푸시합니다

`firebase-config.js` 의 값은 **비밀이 아닙니다.** 접근 통제는 전부 `firestore.rules`
가 합니다 — 로그인하지 않으면 아무것도 못 읽고, 로그인해도 자기 가구 문서만 읽습니다.

### 함께 쓰기

한 사람이 로그인하면 가계부가 하나 만들어집니다. 헤더의 계정 버튼을 눌러 나오는
**6자리 초대 코드**를 상대에게 알려주고, 상대가 같은 주소에서 로그인한 뒤 그 코드를
넣으면 같은 가계부를 씁니다. 코드는 아는 사람만 참여할 수 있고, 참여 규칙은
"자기 자신만 구성원에 추가" 하나만 허용합니다.

로그인 전에 브라우저에 적어 둔 내용이 있으면 **서버로 옮길지 물어봅니다.**

## 데이터

- 자동 저장 위치는 브라우저 `localStorage` 입니다. **브라우저를 바꾸거나 사이트 데이터를 지우면 사라집니다**
- 헤더의 `파일로 저장` 으로 JSON 백업을 만들고, `불러오기` 로 되돌리거나 다른 기기로 옮깁니다
- 큰 작업 뒤에는 백업을 한 번 받아두세요
