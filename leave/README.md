# 육아휴직 급여 계산기

부부가 각각 언제·얼마나 육아휴직을 쓰느냐에 따라 **매달 손에 들어오는 돈**이 어떻게 달라지는지 계산하는 정적 웹 페이지입니다.

**→ https://soverdoes.github.io/parental-leave-calc/**

## 무엇을 계산하나

- **월별 수령액** — 근무월은 실수령액, 휴직월은 고용보험 육아휴직 급여
- **6+6 부모육아휴직제** 특례 적용 여부와 회차별 상한
- **출산전후휴가 90일** 자동 삽입 (이 기간 동안 육아휴직 회차는 멈췄다가 이어짐)
- **시나리오 비교** — 휴직 시작 시점을 옮겼을 때의 총액 차이
- 휴직 후 **퇴사**를 전제로 한 계산

## 계산 기준 (2025년 개편)

| 구간 | 소득대체율 | 월 상한 |
|---|---|---|
| 육아휴직 1~3회차 | 통상임금 100% | 2,500,000원 |
| 육아휴직 4~6회차 | 통상임금 100% | 2,000,000원 |
| 육아휴직 7회차~ | 통상임금 80% | 1,600,000원 |
| 출산전후휴가 (90일) | 통상임금 100% | 2,100,000원 |

**6+6 부모육아휴직제** — 자녀 생후 18개월 이내에 부모가 모두 육아휴직을 쓰면 각자 첫 6회차에 통상임금 100%, 상한이 월 200 → 250 → 300 → 350 → 400 → 450만원으로 상승.

임신 중 육아휴직도 대상입니다. 고용보험법 시행령 제95조의3 제2항이 임신 중인 태아를 자녀로, 임신부와 배우자를 부모로 간주합니다. 회차는 리셋되지 않고 합산됩니다(제95조 제2항).

## 개인정보

**입력한 값은 브라우저를 벗어나지 않습니다.**

- 급여명세서 이미지는 업로드되지 않습니다. [Tesseract.js](https://tesseract.projectnaptha.com/)로 **브라우저 안에서만** 글자를 인식합니다
- 입력값은 `localStorage`(이 기기)에만 저장됩니다
- 「내 계획 링크 복사」는 입력값을 주소의 `#` 뒤에 담습니다. URL 프래그먼트는 서버로 전송되지 않지만, **주소 자체에 금액이 들어 있으므로 이 링크는 공유하지 마세요**
- 서버가 없습니다. GitHub Pages가 정적 파일만 내려줍니다

## 쓰는 법

1. 두 사람의 **기본급 · 식대 · 실수령액**을 입력 (명세서 이미지를 올려 자동 인식도 가능)
2. **임신 또는 출산 예정일**을 입력 — 수정일 기준 266일(38주)로 서로 연동됩니다
3. 각자의 **휴직 시작 시점과 개월 수**를 조정
4. 월별 표를 **엑셀로 저장**하거나 **표 복사** 후 스프레드시트에 붙여넣기

### 통상임금 주의

육아휴직 급여는 실수령액이 아니라 **통상임금** 기준입니다. 기본급·식대처럼 정기적·일률적으로 지급되는 항목의 합이며, **연장·야간·휴일근로수당은 제외**됩니다. 식대의 통상임금 포함 여부는 회사 규정 확인이 필요합니다.

## 확인이 필요한 것

- 육아휴직 **1년 6개월 연장 요건**(부모 각각 3개월 이상)에 임신 중 사용분이 포함되는지는 확인되지 않았습니다
- 출산전후휴가 급여는 **우선지원대상기업** 기준입니다. 대규모기업은 최초 60일을 회사가 통상임금 전액으로 지급합니다
- 부모급여·아동수당·첫만남이용권·퇴직금·상여금은 계산에 **포함되지 않았습니다**

급여 상한과 제도 요건은 매년 바뀝니다. 실제 신청 시점 기준은 [고용보험](https://www.ei.go.kr) 또는 고객상담센터 **1350**에서 확인하세요. 이 페이지는 계획 수립을 돕는 계산 도구이며 법률·노무 자문이 아닙니다.

## 기술

의존성 없는 단일 HTML 파일입니다. 빌드 과정이 없습니다.

- [Tesseract.js](https://github.com/naptha/tesseract.js) 5.1.1 — 클라이언트 OCR (한국어)
- [SheetJS](https://sheetjs.com/) 0.18.5 — xlsx 생성
- 폰트: Pretendard (로컬 설치 시) → Noto Sans KR 폴백

라이트/다크 테마 모두 지원합니다.

## 로그인해서 함께 쓰기

오른쪽 위 `로그인` 을 누르면 구글 계정으로 로그인합니다. 로그인하면 입력한 값이
서버에 저장되어 **두 사람이 어느 기기에서 열어도 같은 값**이 보이고, 한쪽이 고치면
다른 쪽 화면에도 바로 반영됩니다. 같이 보고 있으면 상대 프로필이 옆에 뜹니다.

가계부 「곳간」과 같은 계정·같은 가구를 씁니다. 곳간에서 초대 코드로 이미
합류했다면 여기서는 로그인만 하면 됩니다.

로그인하지 않으면 지금까지처럼 **이 브라우저에만** 저장되고, `내 계획 링크 복사` 로
주소를 주고받아야 합니다.

값의 우선순위는 `주소에 담긴 값 > 서버에 저장된 값 > 이 기기에 저장된 값 > 예시값`
입니다. 링크로 연 값은 로그인 상태라면 그대로 우리 값으로 저장됩니다.
